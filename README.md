# godot-mcp-server
An MCP server that pairs with godot-mcp-toolkit to let Claude Code (or any MCP-compatible assistant) drive the Godot   4.x editor. Runs locally as a stdio↔WebSocket bridge, exposing scene, node, script, and runtime tools so the assistant    can create, inspect, and playtest your project from chat — no manual copying between the AI and Godot.
